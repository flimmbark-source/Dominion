# HUD Screenshot Instructions

The current HUD layout can be previewed by running the development server and navigating to the game in a browser. Use the following steps to reproduce the screenshot captured during testing:

1. Install dependencies (if not already installed):
   ```bash
   npm install
   ```
2. Start the Vite dev server on an available port, for example:
   ```bash
   npm run dev -- --host 0.0.0.0 --port 4173
   ```
3. Open `http://127.0.0.1:4173/` in a browser window at 1280×720 resolution to view the HUD.
4. Capture a screenshot of the canvas once the HUD is visible.

This mirrors the process used to generate the latest HUD reference image shared with the team.
